# Secure Code Assessment

## Objective

This project demonstrates how to identify and fix common security vulnerabilities in a Python login application.

## Files

- vulnerable_login.py
- secure_login.py
- report.md

## Vulnerabilities Identified

- Hardcoded Credentials
- Weak Password
- Unlimited Login Attempts

## Security Improvements

- Strong Password
- Login Attempt Limitation
- Account Lock Mechanism

## Technologies Used

- Python 3
- VS Code
